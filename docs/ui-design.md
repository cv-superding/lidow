# UI 设计规范

对标 Cursor / Windsurf 的现代 AI 编辑器风格：极简、高级、无冗余。

## 设计令牌（styles.css）

| 令牌 | 说明 |
| --- | --- |
| `--bg` / `--bg-panel` / `--bg-elevated` | 三级背景（页面/面板/浮层） |
| `--border` | 8% 透明度分隔线，低对比 |
| `--text` / `--text-dim` | 主文字 / 次要文字 |
| `--accent` | 主色，默认 `#5b8cff`，设置中可自定义 |
| `--shadow` | 双层轻阴影 |

- 扁平 + 大量留白 + 低饱和 + 大圆角（2xl/16px 为基准）
- 深浅双主题：`html.dark` 切换令牌；`theme: system` 跟随系统

## 布局

```
┌──┬──────────────────────────┬─────────┐
│R │ 顶部极简地址栏（状态+停止）│         │
│a ├──────────────────────────┤ 右侧    │
│i │  webview 标签区（沉浸）    │ Harness │
│l │                          │ 对话面板 │
│  │                          │ (可收起) │
└──┴──────────────────────────┴─────────┘
```

- 左侧图标栏：56px，hover 平滑展开到 176px 露出文字
- 纯净模式：一键只留对话内容，彻底沉浸
- 悬浮球（overlay 内渲染）：可拖拽、左键开面板、右键三层停止菜单

## 动效

- 统一缓动 `cubic-bezier(0.22, 1, 0.36, 1)`，面板 250ms、悬停缩放 200ms
- 流式回复实时渲染 + tok/s 指示
